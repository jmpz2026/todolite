# 000 - Setup del proyecto

## Objetivo
Tener backend y frontend arrancando y comunicándose.

## Historias
- Como desarrollador, quiero levantar ambos proyectos con un comando cada uno.
- Como desarrollador, quiero ejecutar las pruebas de cada proyecto con un comando.

## Criterios de aceptación
- [ ] GET http://localhost:3000/api/health responde { "status": "ok" }
- [ ] http://localhost:4200 muestra el texto "TodoLite"
- [ ] La página muestra "API: ok" leyendo /api/health
- [ ] Backend y frontend tienen al menos una prueba unitaria cada uno y pasan

## Fuera de alcance
- Base de datos, tareas, estilos.
